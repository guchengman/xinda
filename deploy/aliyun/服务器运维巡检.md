1. **家里 DDNS 未迁移**：`zengxiao.xinda56.cn` 的 A/AAAA 更新仍写在 Cloudflare，NS 已切走后不再生效，家宽 IP 变化会导致 11 个 CNAME 子域失联。需要确认 DDNS 跑在哪台设备（路由器内置 / 群晖 / Windows / Docker），再改用阿里云 API 或 DDNS-GO。
