## 二、切换步骤（备案通过后执行）

### Step 1　Cloudflare 改解析（关键：必须灰云）

控制台：`https://dash.cloudflare.com/f793d156f808338db320efcc88e58d03/xinda56.cn/dns/records`

| 记录 | 现在 | 改成 |
|---|---|---|
| `www.xinda56.cn` | CNAME → `xinda-89t.pages.dev`（橙云代理） | **A → `8.163.60.184`，代理状态必须是 DNS only（灰云）** |
| `xinda56.cn` | CNAME → `xinda-89t.pages.dev`（橙云代理） | **A → `8.163.60.184`，代理状态必须是 DNS only（灰云）** |

- 橙云（代理）状态下，阿里云备案核查看不到真实源站，可能判定未接入，且 Cloudflare 会拦截/改写流量 → **必须灰云**
- 不要动 `mail` / `pop3` / `smtp.xinda56.cn` 的 CNAME（阿里云企业邮）
- 不要动 Resend 的 4 条记录（DKIM/SPF/rsend）和 `_dmarc`

### Step 2　验证解析生效（约 5–10 分钟）

```powershell
Resolve-DnsName -Name "www.xinda56.cn" -Type A
Resolve-DnsName -Name "xinda56.cn" -Type A
# 期望：返回 8.163.60.184
```

### Step 3　申请 HTTPS 证书

域名解析指向 ECS 后再申请（Let's Encrypt HTTP-01 验证需要域名能回源到本机）。

宝塔面板：网站 → 设置 → SSL → Let's Encrypt → 申请（选 `www.xinda56.cn` 和 `xinda56.cn`）。

申请成功后强制 HTTPS：SSL 页签打开「强制 HTTPS」。

### Step 4　配置 443 监听确认

```bash
ss -lntp | grep 443
curl -I https://www.xinda56.cn/
```

### Step 5　页脚挂备案号（代码改动）

备案号下发后，在 `src/layouts/Layout.astro` 页脚加：

```html
<a href="https://beian.miit.gov.cn/" target="_blank" rel="noopener noreferrer">赣ICP备XXXXXXXX号</a>
```

然后重新 `npm run build`，把 `dist/client` 同步到服务器 `/www/wwwroot/xinda56/`。

### Step 6　切换后回归验证

```bash
for p in / /about/ /contact/ /lines/ganzhou-foshan/ /news/ /services/ /no-such-page/; do
  curl -sS -o /dev/null -w "$p %{http_code} %{size_download}\n" "https://www.xinda56.cn$p"
done
curl -sS -X POST -H "Content-Type: application/json" \
  -d '{"name":"切换后验证","phone":"13800138000"}' https://www.xinda56.cn/api/contact
```

期望：首页 45665 字节、线路页 33982、新闻页 44679、不存在页 404、API 返回 `sent:true`。
